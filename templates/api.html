Endpoints

GET /api/produtos/

Lista produtos com saldo calculado. Filtros: q, categoria, situacao (ok, minimo, ruptura, sem_giro), page, page_size (até 200).

curl -H "Authorization: Bearer {{ token.chave }}" \
  "{{ host }}/api/produtos/?situacao=minimo"

GET /api/saldo/

Saldo por produto e depósito. Filtros: sku, deposito (código), page, page_size.

curl -H "Authorization: Bearer {{ token.chave }}" \
  "{{ host }}/api/saldo/?sku=MER-0001"

Respostas: {"count", "page", "pages", "page_size", "results": [...]}. Sem token ou token inválido: HTTP 401.
